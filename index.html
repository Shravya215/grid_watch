About GridWatch

GridWatch is a smart power grid simulation system developed to demonstrate concepts of Design and Analysis of Algorithms (DAA) and Operating Systems through real-world infrastructure simulations.

The website allows users to:

🌳 Simulate Prim’s and Kruskal’s MST algorithms
💾 Perform Memory Allocation using First Fit, Best Fit and Worst Fit
⚠ Detect faults in power transmission lines

Users can enter custom inputs, run simulations, observe outputs, and understand how smart power grid systems work.
